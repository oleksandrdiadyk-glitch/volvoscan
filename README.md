# VolvoScan P3 — VIDA Diagnostic & Service Mobile App
**Специализированный мобильный диагностический комплекс для платформы Volvo P3 (EUCD)**

Разработано специально для:
* **Автомобиль:** Volvo XC70 AWD (Модельный год: 2008)
* **VIN:** `YV4BZ982581009482`
* **Двигатель:** 3.2L 6-цилиндровый бензиновый атмосферный (`B6324S`, 235 л.с. / 320 Нм, нормы ULEV2)
* **Коробка передач:** 6-ступенчатая гидромеханическая АКПП Aisin Warner `TF-80SC Geartronic`
* **Полный привод:** Электрогидравлическая муфта `Haldex Generation 4 (DEM)`
* **Тормозная система:** `BCM` с электронным стояночным тормозом (`EPB`)

---

## 🚀 Возможности приложения

### 1. 🩺 Глубокая диагностика всех 10 блоков (VIDA DTC)
* Опрос модулей по протоколам **UDS (ISO 14229)** и **ISO 15765-4 (500 kbps HS-CAN / MS-CAN)**:
  * `ECM` (7E0 / 7E8) — Блок управления двигателем 3.2
  * `TCM` (7E1 / 7E9) — Блок управления АКПП Aisin TF-80SC
  * `BCM` (760 / 768) — Тормозная система, ABS, DSTC, стояночный тормоз EPB
  * `CEM` (726 / 72E) — Центральный электронный модуль (шлюз)
  * `DEM` (7A0 / 7A8) — Модуль полного привода Haldex Gen 4
  * `DIM` (720 / 728) — Приборная панель
  * `CCM` (733 / 73B) — Двухзонный климат-контроль
  * `SRS` (772 / 77A) — Блок подушек безопасности
  * `DDM` / `PDM` — Дверные модули водителя и пассажира
* Расшифровка заводских кодов ошибок Volvo (например: `ECM-3002`, `DEM-0007`, `CEM-3A00`, `BCM-0100`) с подробным описанием неисправности на русском языке.
* Стирание кодов неисправностей (DTC Clear) во всех блоках одной кнопкой.

### 2. ⚙️ Специальные сервисные функции
* **🅿️ Электронный ручник (EPB):**
  * Перевод задних суппортов в сервисный режим (*разведение колодок*) для их физической замены без повреждения сервоприводов.
  * Сведение суппортов и автоматическая калибровка рабочего зазора после установки новых колодок.
* **🛢️ Контроль уровня и температуры масла АКПП Aisin TF-80SC:**
  * Отображение температуры ATF в реальном времени с подсветкой целевого окна **50°C – 60°C** (заводской регламент Volvo для выставления уровня по контрольной переливной трубке).
  * Сброс счетчика деградации трансмиссионного масла после замены ATF.
* **🔧 Сброс сервисного интервала (SRI):**
  * Сброс напоминания на приборной панели («Срок регулярного обслуживания») на 15 000 км / 12 месяцев в один клик.
* **🚗 Проверка реального пробега:**
  * Сравнение данных одометра из трех независимых блоков памяти (`DIM`, `CEM`, `TCM`) для выявления возможной скрутки пробега.

### 3. 📊 Живые параметры (Live Data)
* **Двигатель 3.2 B6324S:**
  * Обороты двигателя (RPM), температура ОЖ, температура впуска.
  * Топливные коррекции смеси (LTFT / STFT по Банку 1 и Банку 2).
  * Давление в топливной рампе (бар).
  * Индивидуальный счетчик пропусков зажигания по каждому из 6 цилиндров (`Ц1..Ц6`).
  * Фазы газораспределения VVT (впуск и выпуск).
* **АКПП & Полный привод:**
  * Температура масла АКПП, текущая передача Geartronic, проскальзывание гидротрансформатора (Lock-up Slip RPM).
  * Ток электродвигателя масляного насоса Haldex 4 (в миллиамперах: норма 700–1100 мА, засор сетки > 1800 мА).
  * Давление в муфте полного привода.
